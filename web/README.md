# موقع وِرد — المصدر

المستودع هو مصدر الموقع. النشر (`web-deploy/deploy.mjs`) يبني الملفات من هنا ويرفعها على Cloudflare؛ لا يوجد أي تعديل على الموقع المنشور خارج هذا الفولدر.

## البنية
- `site/` — كل ملفات الموقع كما تُخدَم (صفحات، بيانات، خطوط، صور مخزنة نصًا base64 كما في الـ Worker).
- `ui/` — أجزاء `ui.js` بالترتيب: `00-core.js` كود التطبيق الأساسي، وبعده الوحدات (`NN-name.js`) كل واحدة تبدأ بعلامة `/*name*/`.
- `css/` — أجزاء `styles.css` بنفس الفكرة.
- `manifest.json` — قائمة الملفات ونوع كل ملف وترتيب الأجزاء.
- `build.mjs` — يجمع الملفات بالشكل اللي الـ Worker محتاجه.

## النشر
GitHub Actions ← «Deploy website (manual)» ← Run workflow.
- يقارن الناتج بالمنشور ويكتب الملفات اللي اتغيّرت؛ لو مفيش تغيير ما بيرفعش حاجة.
- يزوّد إصدار الكاش في `sw.js` تلقائيًا عند أي تغيير.
- `dry = yes`: بناء ومقارنة بدون نشر.
- بعد كل نشر: روبوت الفحص (`qa/qa.mjs`) يشتغل لوحده، والصور في فرع `qa-shots`.

## الخطة
الوحدات في `ui/` و`css/` هتتدمج واحدة واحدة جوه `00-core`، والمراقبات والمؤقتات و`!important` اللي ما بقاش ليها لازمة هتتشال، مع فحص كامل بعد كل خطوة.
