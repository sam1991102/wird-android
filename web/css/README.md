# ألوان وِرد — القاعدة الوحيدة

**أي لون في التطبيق ييجي من رمز (`var(--اسم)`)، مش مكتوب بقيمته.**
قيم الرموز متعرّفة مرة واحدة لكل مظهر، فتغيير لون في مظهر = تعديل سطر واحد، وكل الصفحات تتغيّر معاه.

## فين القيم

| المظهر | الملف | المكان |
|---|---|---|
| كلاسيكي نهاري | `00-core.css` | `:root{--bg…}` |
| كلاسيكي ليلي | `00-core.css` | `html.dark{…}` |
| كلاسيكي ورقي (سيبيا) | `00-core.css` | `html.sepia{…}` |
| إبداعي نهاري | `04-skin-ios.css` | `html.ios` و`html.ios:not(.dark)` |
| إبداعي ليلي | `04-skin-ios.css` | `html.ios.dark` |
| الرموز المشتقة (تتحسب من اللي فوق) | آخر `00-core.css` و`04-skin-ios.css` | «الرموز الدلالية» |

## أي رمز لأي حاجة

| الاستخدام | الرمز |
|---|---|
| خلفية الصفحة | `--bg` |
| خلفية البطاقة | `--paper` (والدرجة التانية `--paper-2`) |
| النص الأساسي | `--ink` |
| النص الثانوي / الوصف تحت العنوان | `--muted` (أو `--ink-2` لو أغمق شوية) |
| الحدود والفواصل | `--line` (والأخف `--line-2`) |
| اللون الأساسي (أزرار، المختار) | `--primary` والنص فوقه `--on-primary` |
| اللون الأساسي كنص أو أيقونة | `--primary-ink` |
| لون المظهر المميّز (ذهبي في الكلاسيكي، كحلي في الإبداعي) | `--gold` / `--gold-2` |
| ذهبي كنص | `--gold-ink` |
| زرار ذهبي والنص فوقه | `--gold-2` و`--on-gold` |
| خلفية خفيفة بلون المظهر (تلميح، شريحة) | `--tint` (أخف: `--tint-2`) وحدودها `--tint-line` |
| خلفية غامقة (شريط، شريحة غامقة) والنص فوقها | `--deep` و`--on-hero-acc` |
| حذف / خطر | `--danger` (كنص: `--danger-ink`) |
| نجاح | `--success` |
| مفتاح مقفول | `--switch-off` |
| تعتيم ورا النوافذ | `--scrim` |
| درجة شفافة من رمز | `color-mix(in srgb, var(--gold) 20%, transparent)` |

## مستثنى عن قصد (ليه ألوانه الخاصة)

ورق المصحف وخطه (`.mp-page`)، بطاقات السماء والصلاة اللي بتتغيّر مع وقت اليوم (`#skyCard` `.sk-` `.da-` `.ph-`)،
شاشة رنين المنبّه والأذان (`.al-ov` `.adhan-ov`)، ركن الطفل (`.kd-`)، ألوان أيقونات الإعدادات (`.nt-ic`)، الشعار وشاشة البداية.

## الحماية

- **`theme-lint.mjs`** (جوه البناء نفسه): لو أي ملف هنا زاد فيه لون مكتوب بقيمته، البناء بيقف — النشر وتطبيق أندرويد.
  لما تنقل ألوان قديمة للرموز: `node theme-lint.mjs --update` علشان العدد الجديد الأقل يتسجّل (العدد بيقل بس، ما بيزيدش).
- **`qa/theme/audit.mjs`**: بيفتح ٢٣ صفحة ونافذة في المظاهر الخمسة، ويقول على أي لون ظاهر مش من الرموز (والقاعدة اللي حطّته)، وأي نص تباينه أقل من المطلوب.
  `SITE=http://localhost:8787/ node qa/theme/audit.mjs` — لازم يطلع صفر في الاتنين قبل أي رفع.

## الأيقونات والمقاسات
- **أيقونة على مربع غامق** (بلاطات الأذكار، الإذاعة): المربع `--deep` والأيقونة `--on-hero-acc`، ومقاسها من قاعدة واحدة (`.l2-si svg` = 26px وسُمك 1.5). ماتحطش لون ولا مقاس جوه الـjs.
- **أيقونة ذهبي على مربع فاتح** (اختصارات المواقيت، علامة المصحف): الأيقونة `--gold-ink` مش `--gold` (الذهبي العادي خفيف على الفاتح).
- **مربعات الإعدادات الملوّنة** (`.nt-ic`): لون الصف في `--c`، والأيقونة بتتغمّق/تتفتّح تلقائيًا بخلطها مع `--ink`.
- **فحص**: `node qa/theme/icons.mjs` — بيقيس تباين كل أيقونة مع خلفيتها الفعلية (≥3:1)، وإن الأيقونات من نفس النوع ليها نفس المقاس واللون، وإن مفيش نص مقصوص أو طالع برّه الشاشة. لازم يطلع أصفار قبل أي رفع.

## المقاسات
- **حجم الخط**: سلّم واحد بس — `--t-2xs` 11 · `--t-xs` 12 · `--t-sm` 13 · `--t-md` 14 · `--t-base` 16 · `--t-lg` 18 · `--t-xl` 20 · `--t-2xl` 24 · `--t-3xl` 28 · `--t-4xl` 32 (عناوين الصفحات كلها). و`--t-glyph` 22 للرموز اللي بتتكتب كحرف (× ← ★)، و`--t-read` 22 لنص الآيات والأذكار جوه الصفحات. ماتكتبش `15px` ولا `.9rem`.
- **الاستدارة**: `--rd-2xs` 4 · `--rd-xs` 8 · `--rd-s` 12 · `--rd-m` 16 · `--rd-l` 20 · `--rd-xl` 26 · `--rd-pill`. و`50%` للدوائر و`0` مسموحين.
- **المسافات** (padding / margin / gap): `--s2` `--s4` `--s6` `--s8` `--s10` `--s12` `--s14` `--s16` `--s20` `--s24` `--s28` `--s32` `--s40` `--s48` (الرقم = البكسل). `--sp-1..5` أسماء قديمة بتشاور على `--s8..--s48`. و`0` و`1px` والقيم السالبة مسموحين.
- **مستثنى عن قصد**: نص المصحف والأذكار (بيتغيّر مع «حجم خط الأذكار» من `--text-size`)، والرسوم، والقيم المحسوبة بـ`calc/clamp`.
- **القفل**: `theme-lint.mjs` جوه البناء بيعدّ الألوان وأحجام الخط والاستدارات والمسافات المكتوبة بإيدها لكل ملف؛ لو زادت البناء بيقف.

## الخطوط
- `--font-ui` الواجهة · `--font-text` نص الأذكار · `--font-quran` القرآن · `--font-deco` زخرفي · `--font-hand` تحية الرئيسية.
- `--font-accent` **خط اللمسة**: اسم اليوم و«اجعل لسانك رطبًا» وعناوين **كل** الصفحات وصفحة الترحيب — ده من هوية التطبيق. القاعدة في آخر `00-core.css`؛ أي صفحة جديدة عنوانها يتضاف هناك. في الإبداعي هو الخط الوحيد غير خط النظام (غير القرآن). عايز تضيف/تشيل مكان؟ غيّر `font-family` بتاعه لـ/من `var(--font-accent)`.
- أسماء الخطوط بالاسم مسموحة جوه `@font-face` بس.

## رموز إضافية
- `--shade` (أسود): أساس كل الظلال وطبقات التغميق — `color-mix(in srgb,var(--shade) 20%,transparent)`.
- `--knob` (أبيض): زرار المفتاح (السويتش) نفسه.
- `--scrim`: الطبقة الغامقة ورا النوافذ.
- `--card` اتشال؛ استخدم `--paper`.

## المستثنى من القفل
القائمة في `EXEMPT` جوه `theme-lint.mjs`: ورق المصحف ووضعه الليلي، السما ورسوم الرئيسية حسب الوقت، ركن الأطفال، شاشة الأذان، شاشة البداية والمعالج، وضع التركيز، زرار المفضّلة، شريط الآيفون الشفاف. دي أجزاء متصمّمة بألوانها؛ أي جزء جديد ما يتضافش هنا إلا لو ليه نفس السبب.

## المكوّنات الموحّدة (كل الصفحات شكل واحد)
- **مربع الأيقونة**: خلفية `--chip-bg` (اللون الأساسي ١٠٪) والأيقونة `--chip-ink`. القاعدة في آخر `00-core.css` — نوع جديد؟ ضيف كلاسه للقائمة هناك، ماتدّيلوش لون. القفل بيعدّ أي مربع `-ic` بلون خاص.
- **الحالي/المختار بس** (الصلاة القادمة) بيتملي باللون الأساسي.
- **رأس الصفحات الفرعية**: خلفية الصفحة + خط سفلي رفيع + العنوان بخط اللمسة — زي الصفحات الرئيسية.
- **الأزرار**: الأساسي أخضر (و`.btn-gold` بقى نفسه). الدهبي للعدّاد والصلاة القادمة بس.
- **الاستثناءات المقصودة**: كروت السما (`.w-sky`)، رسومات الأطفال، صفحات المصحف.

## الكلاسيكي النهاري: أبيض بحدود رفيعة
- الصفحة والكروت أبيض (`--bg` / `--paper`)، والفصل بالحدود (`--line`). من غير بيج.
- `--tint*` (الخلفيات الخفيفة) في النهاري محايدة؛ في الليلي والورقي دهبي دافي.
- الخلفيات الخفيفة الملوّنة = `--chip-bg` (أخضر فاتح) مش دهبي. الدهبي للتمييز الدلالي بس (درجة الحديث «حسن»، العدّاد، الصلاة القادمة).
- حلقة التركيز والحقل النشط والمفاتيح المفعّلة: `--focus` / `--primary`.
