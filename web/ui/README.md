# ui/ — قواعد الأداء

كل وحدة هنا بتشتغل جوه نفس الصفحة، فأي مراقب أو مؤقّت زيادة بيتقل التطبيق كله. استخدم المشترك من `00b-dom.js`:

| عايز | استخدم | مش |
|---|---|---|
| تعرف إن عناصر اتضافت/اتشالت | `__wOnDom(fn)` | `new MutationObserver(fn).observe(document.body,{childList:true,subtree:true})` |
| تعرف إن الصفحة الظاهرة اتغيّرت | `__wOnView(fn)` | مراقبة `data-view` |
| عدّاد كل ثانية | `__wEverySec(fn)` | `setInterval(fn,1000)` |
| تستنى عنصر يظهر | `__wWait(test,fn)` | تكرار بمؤقّت |

- `fn` لازم تكون آمنة لو اتنادت كذا مرة، ورخيصة: اكتب النص بس لو اتغيّر (`if(e.textContent!==v)e.textContent=v`).
- اللي بيتحدّث كل ثانية يتضاف لقائمة `TICKING` في `00b-dom.js` عشان ما يصحّيش باقي الوحدات.
- **القفل**: `ui-lint.mjs` جوه البناء بيعدّ المراقبين والمؤقّتات المستقلّين لكل ملف؛ لو زادوا البناء بيقف.
- **القياس**: `SKIN=ios node qa/perf.mjs` (معالج مبطّأ ٤ مرات زي موبايل متوسط).
