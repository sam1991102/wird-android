# بيانات تدخل في تطبيق أندرويد

`qdata/` المصحف المدني والتفسير الميسر، علشان يشتغلوا من أول تثبيت من غير إنترنت:

- `p/<رقم الصفحة>.json` صفحات المصحف الـ٦٠٤ (نفس شكل quran.com v4، بدون الترجمة والنطق اللاتيني)
- `f/p<رقم الصفحة>.woff2` خط مجمع الملك فهد (QCF v2) لكل صفحة
- `t/<رقم السورة>.json` التفسير الميسر: `{"رقم الآية": "النص"}`

بتتنزّل وتتحدّث بالسكربت `tools/fetch-quran-data.mjs` (خطوة البناء «Quran data»)، وبيتأكد إن العدد ٦٢٣٦ آية.
`web/app-bundle.mjs` بيحطها في التطبيق تحت `/qdata/` ويوقف البناء لو أي ملف ناقص.
